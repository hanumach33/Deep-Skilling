# Git Hands-On Lab 4

## Objective

Learn how to create merge conflicts, identify conflicting changes, resolve conflicts using Git and P4Merge, update `.gitignore`, and complete the merge successfully.

## Prerequisites

- Git installed
- Existing Git repository
- Hands-on 3 completed
- P4Merge configured as merge tool

## Topics Covered

- Git Merge Conflict
- Git Diff
- Git Difftool
- P4Merge
- 3-Way Merge
- .gitignore
- Branch Cleanup

## Commands Covered

- git status
- git branch
- git checkout
- git switch
- git add
- git commit
- git diff
- git difftool
- git merge
- git mergetool
- git log
- git branch -d
