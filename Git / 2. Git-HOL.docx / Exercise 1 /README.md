# Git Hands-On Lab 2

## Objective

Learn how to ignore unwanted files and directories in a Git repository using the `.gitignore` file.

## Prerequisites

- Git installed
- Git repository initialized
- Notepad++ configured as the default editor
- Local and remote Git repository available

## Topics Covered

- .gitignore
- Ignoring log files
- Ignoring folders
- git status verification

## Commands Covered

- mkdir
- touch
- echo
- git status
- git add
- git commit
