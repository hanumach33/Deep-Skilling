# Git Hands-On Lab 3

## Objective

Learn how to create branches, switch between branches, commit changes, compare branches, merge branches into the master branch, and delete merged branches.

## Prerequisites

- Git installed
- Existing Git repository
- P4Merge installed and configured
- Basic knowledge of Git commands

## Topics Covered

- Git Branch
- Git Checkout
- Git Switch
- Git Merge
- Git Diff
- Git Log
- Branch Deletion

## Commands Covered

- git branch
- git switch
- git checkout
- git status
- git add
- git commit
- git diff
- git difftool
- git merge
- git log
- git branch -d
