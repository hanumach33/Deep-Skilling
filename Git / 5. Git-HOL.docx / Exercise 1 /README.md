# Git Hands-On Lab 5

## Objective

Learn how to synchronize a local Git repository with a remote repository by verifying repository status, pulling the latest changes, pushing local commits, and validating the updates on the remote repository.

## Prerequisites

- Git installed
- Local Git repository
- Remote GitHub/GitLab repository
- Previous hands-on completed successfully

## Topics Covered

- Repository Status
- Branch Listing
- Git Pull
- Git Push
- Remote Repository Verification

## Commands Covered

- git status
- git branch
- git branch -a
- git pull
- git push
- git remote -v
- git log
