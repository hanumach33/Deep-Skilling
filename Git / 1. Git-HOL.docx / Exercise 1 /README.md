# Git Hands-On Lab 1

## Objective

Learn the basic Git commands by creating a local repository, configuring Git, integrating Notepad++ as the default editor, and pushing the repository to a remote Git repository.

## Software Required

- Git Bash
- GitHub or GitLab Account
- Notepad++

## Topics Covered

- Git Installation
- Git Configuration
- Git Default Editor
- Git Repository Initialization
- Git Status
- Git Add
- Git Commit
- Git Push
- Git Pull

## Commands Covered

- git --version
- git config
- git init
- git status
- git add
- git commit
- git remote add origin
- git pull
- git push
