# Exercise 1 - Consuming REST API in React

## Objective

Create a React application named **fetchuserapp** to consume a REST API and display user details.

## Prerequisites

- Node.js
- npm
- Visual Studio Code

## Technologies Used

- React
- JavaScript
- Fetch API

## Components

- Getuser

## Concepts Covered

- REST API
- Fetch API
- componentDidMount()
- State
- Class Components

## Expected Output

- Fetch a random user.
- Display the user's title.
- Display the user's first name.
- Display the user's profile picture.
