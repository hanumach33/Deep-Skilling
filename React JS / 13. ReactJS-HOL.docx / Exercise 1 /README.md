# Exercise 1 - Blogger App using Conditional Rendering

## Objective

Create a React application named **bloggerapp** that displays Book Details, Blog Details, and Course Details using different conditional rendering techniques.

## Prerequisites

- Node.js
- npm
- Visual Studio Code

## Technologies Used

- React
- JavaScript
- JSX

## Components

- BookDetails
- BlogDetails
- CourseDetails

## Concepts Covered

- Conditional Rendering
- List Rendering
- map()
- Keys
- JSX

## Expected Output

- Display Book Details
- Display Blog Details
- Display Course Details
- Render lists using map() with keys
