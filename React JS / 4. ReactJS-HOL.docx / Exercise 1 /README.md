# Exercise 1 - React Component Lifecycle

## Objective

Create a React application named **blogapp** to demonstrate React lifecycle methods by fetching blog posts from an external REST API.

## Prerequisites

- Node.js
- npm
- Visual Studio Code

## Project Name

blogapp

## Technologies Used

- React
- JavaScript
- Fetch API
- JSX
- CSS

## Concepts Covered

- Class Components
- State
- Constructor
- componentDidMount()
- componentDidCatch()
- Fetch API

## Components

- App
- Posts
- Post

## Expected Output

Display all blog posts retrieved from:

https://jsonplaceholder.typicode.com/posts
