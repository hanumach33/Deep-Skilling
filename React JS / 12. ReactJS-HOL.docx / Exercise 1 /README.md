# Exercise 1 - Conditional Rendering in React

## Objective

Create a React application named **ticketbookingapp** to demonstrate conditional rendering based on user login status.

## Prerequisites

- Node.js
- npm
- Visual Studio Code

## Technologies Used

- React
- JavaScript
- JSX

## Components

- LoginControl
- LoginButton
- LogoutButton
- Greeting
- GuestGreeting
- UserGreeting

## Concepts Covered

- Conditional Rendering
- State
- Event Handling
- Functional Components
- Class Components

## Expected Output

- Guest users can view flight details.
- Logged-in users can book tickets.
- Login and Logout buttons toggle between Guest and User pages.
