# Exercise 1 - Office Space Rental App using JSX

## Objective

Create a React application named **officespacerentalapp** using JSX to display office space details.

## Prerequisites

- Node.js
- npm
- Visual Studio Code

## Technologies Used

- React
- JSX
- JavaScript

## Concepts Covered

- JSX
- JavaScript Expressions
- Inline CSS
- Conditional Styling
- Rendering Lists

## Components

- App

## Expected Output

- Display office space details.
- Display office image.
- Display multiple office records.
- Rent should appear in **Red** if below 60000 and **Green** otherwise.
