# Exercise 1 - ES6 Features in React

## Objective

Create a React application named **cricketapp** to demonstrate ES6 features such as map(), arrow functions, destructuring, and array merging.

## Prerequisites

- Node.js
- npm
- Visual Studio Code

## Technologies Used

- React
- JavaScript ES6

## Components

- ListOfPlayers
- IndianPlayers

## Concepts Covered

- map()
- filter()
- Arrow Functions
- Destructuring
- Spread Operator
- Conditional Rendering

## Expected Output

- Display all players.
- Display players with score below 70.
- Display odd and even team players.
- Merge T20 and Ranji Trophy player arrays.
