# Exercise 1 - Jest Mocking with Axios

## Objective

Create a React application named **gitclientapp** that fetches GitHub repositories using Axios and unit tests the API module using Jest mocks.

## Prerequisites

- Node.js
- npm
- Visual Studio Code

## Technologies Used

- React
- Axios
- Jest

## Components

- App
- GitClient

## Concepts Covered

- Axios
- REST API
- useEffect()
- Jest Mocking
- Unit Testing

## Expected Output

- Display repository names for a GitHub user.
- Mock Axios in unit tests.
- Verify repository data without making real API calls.
