# Exercise 1 - React Events

## Objective

Create a React application named **eventexamplesapp** to demonstrate React event handling and synthetic events.

## Prerequisites

- Node.js
- npm
- Visual Studio Code

## Technologies Used

- React
- JavaScript
- JSX

## Components

- EventExamples
- CurrencyConvertor

## Concepts Covered

- Event Handling
- Synthetic Events
- Passing Arguments
- Multiple Event Methods
- State
- setState()

## Expected Output

- Increment and Decrement Counter
- Say Hello
- Say Welcome
- Synthetic Event
- Currency Converter
