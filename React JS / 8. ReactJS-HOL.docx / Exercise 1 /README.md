# Exercise 1 - React State

## Objective

Create a React application named **counterapp** to demonstrate the use of React State.

## Prerequisites

- Node.js
- npm
- Visual Studio Code

## Technologies Used

- React
- JavaScript
- JSX

## Components

- CountPeople

## Concepts Covered

- Class Components
- Constructor
- State
- setState()
- Event Handling

## Expected Output

- Login button increments the number of people entered.
- Exit button increments the number of people exited.
