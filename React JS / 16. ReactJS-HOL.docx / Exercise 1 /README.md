# Exercise 1 - React Form Validation

## Objective

Create a React application named **mailregisterapp** to demonstrate React Form Validation using controlled components.

## Prerequisites

- Node.js
- npm
- Visual Studio Code

## Technologies Used

- React
- JavaScript
- JSX

## Components

- Register

## Concepts Covered

- React Forms
- Form Validation
- Controlled Components
- handleChange()
- handleSubmit()

## Validation Rules

- Name should contain at least 5 characters.
- Email should contain '@' and '.'.
- Password should contain at least 8 characters.

## Expected Output

Validate the form before successful submission.
