# Exercise 1 - React Forms

## Objective

Create a React application named **ticketraisingapp** to demonstrate React Forms using controlled components.

## Prerequisites

- Node.js
- npm
- Visual Studio Code

## Technologies Used

- React
- JavaScript
- JSX

## Components

- ComplaintRegister

## Concepts Covered

- React Forms
- Controlled Components
- Textbox
- Textarea
- Event Handling
- handleChange()
- handleSubmit()

## Expected Output

- Accept employee name.
- Accept complaint.
- Generate a complaint reference number.
- Display the reference number using an alert.
