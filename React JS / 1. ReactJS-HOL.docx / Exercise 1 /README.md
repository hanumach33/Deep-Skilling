# Exercise 1 - Create Your First React Application

## Objective

Create your first React application using Create React App and display a heading on the home page.

## Prerequisites

- Node.js
- npm
- Visual Studio Code

## Project Name

myfirstreact

## Technologies Used

- React
- JavaScript
- HTML
- CSS

## Steps

1. Install Node.js and npm.
2. Create a React application using Create React App.
3. Open the project in Visual Studio Code.
4. Replace the default App.js content.
5. Run the application.
6. Verify the output in the browser.

## Expected Output

```
Welcome to the first session of React
```
