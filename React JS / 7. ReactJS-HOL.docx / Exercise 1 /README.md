# Exercise 1 - React Props

## Objective

Create a React application named **shoppingapp** to demonstrate the use of Props and rendering a list of shopping cart items.

## Prerequisites

- Node.js
- npm
- Visual Studio Code

## Technologies Used

- React
- JavaScript
- JSX

## Components

- OnlineShopping
- Cart

## Concepts Covered

- Class Components
- Props
- Arrays
- ReactDOM.render()

## Expected Output

Display five shopping cart items with their names and prices.
